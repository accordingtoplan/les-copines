# Les Copines

Portfolio site for Les Copines, Berlin. One HTML file, no build step.

- `index.html`: the whole site. Cases live in the `CASES` list near the bottom.
- `img/`: photos. Portrait (4:5) works best, at least 1200px wide.

## Updating with AI

Open this folder in Claude (or any AI coding tool) and ask in plain language:

- "Add a new case for Hotel X in Munich, 2026, with these three photos."
- "Change the email address to sandra@lescopines.de."
- "Replace the Nômade Temple photos with the new ones in img/."

Changes go live a minute after they are pushed to `main` (GitHub Pages).

## Test versions

- `/` V1: editorial, Helvetica, rows of two and three.
- `/v2/` V2: edge-to-edge images, small uppercase labels, product-style index (after Acne Studios).
- `/v3/` V3: floating panel nav, bento grid, filters, grid/list toggle, case drawer (after Hard Sun and Köppen).

All three share `img/`. A switcher in the corner jumps between them.
